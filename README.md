# IAC Module CI/CD Pipeline

This repository contains a reusable GitHub Actions workflow designed for **OpenTofu/Terraform module pipelines**. It includes:

- Security and validation checks (`Checkov`, `TFLint`)
- Auto-generation of Terraform docs (`terraform-docs`)
- Supported branching strategy: Trunk-based
- Publishing to Artifactory (on `main` branch)

---

## Usage

### How to increase version

The module version is controled by the **CHANGELOG.md** file, in order to increase it you should add a new one following the example


```
# v0.2.0 05-04-2025

## Changes

- Added support for CDN
```

#### Important: The whole syntax must be respected if your version is v1.2.3 then the first line in your file should be "# v1.2.3 [month]-[day]-[year]"

### Example: `.github/workflows/ci.yml`

```yaml
name: CI Pipeline
on:
  push:
    branches:
      - 'feature/**'
      - 'main'
    paths-ignore:
      - 'docs/**'
      - '.github/**'
  pull_request:
    branches:
      - main
    paths-ignore:
      - 'docs/**'
      - '.github/**'
permissions:
  id-token: write
  contents: write
jobs:
  ModuleTemplate:
    uses: IBK-LABS/dso-workflows/.github/workflows/ci-iac-module.yml@main
    with:
      module_name: 'ibk-sample-module'
      module_provider: 'sample'
    secrets:
      private_key: '${{ secrets.PRIVATE_KEY }}'
```

## Inputs

| Name              | Type      | Secret | Required | Default  | Description                                                           |
| ----------------- | --------- | ------ | -------- | -------- | --------------------------------------------------------------------- |
| `module_name`     | `string`  | ❌ No  | ✅ Yes    | –        | Name of the Terraform module following the name convention: ibk-[resource/use-case]-module      |
| `module_provider` | `string`  | ❌ No  | ✅ Yes    | –        | Tofu provider: [aws/azure/gpc/jfrog...etc]  -> If not in the list please ask focal devsecops                |
| `private_key`     | `string`  | ✅ Yes | ✅ Yes    | –        | Already embedded in project value should be the literal ${{ secrets.PRIVATE_KEY }}                     |
